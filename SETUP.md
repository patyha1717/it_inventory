## 🚀 Quick Start (5 minutes)

### Step 1: Clone & Setup
```bash
git clone https://github.com/patyha1717/it_inventory.git
cd it_inventory
git checkout laravel-12-migration
```

### Step 2: Install Dependencies
```bash
composer install
npm install  # Optional: for frontend assets
```

### Step 3: Configure Environment
```bash
cp .env.example .env
php artisan key:generate
```

### Step 4: Database Setup
Edit `.env`:
```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=itms_prod
DB_USERNAME=root
DB_PASSWORD=
```

### Step 5: Run Migrations
```bash
php artisan migrate
```

### Step 6: Start Server
```bash
php artisan serve
```

Visit: **http://localhost:8000**

## ⚙️ Configuration

### Database (config/database.php)
```env

DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=itms_prod
DB_USERNAME=root
DB_PASSWORD=
DB_CHARSET=utf8mb4
```

### Mail (config/mail.php)
```env
MAIL_MAILER=smtp
MAIL_HOST=email-smtp.ap-south-1.amazonaws.com
MAIL_PORT=587
MAIL_USERNAME=smtp-key
MAIL_PASSWORD=smtp-secret-key
MAIL_ENCRYPTION=tls

```

```env
APP_NAME="IT Inventory"
APP_ENV=local
APP_DEBUG=true
```

## 🐛 Troubleshooting

### Problem: Database Connection Error
```bash
# Check MySQL is running
# Verify DB_HOST, DB_USERNAME, DB_PASSWORD in .env
```

### Problem: Port 8000 Already in Use
```bash
php artisan serve --port=8001
```

### Problem: Permission Denied
```bash
chmod -R 775 storage bootstrap/cache
```

### Problem: Key Not Set
```bash
php artisan key:generate
```
